🚨 Claude can now build a $10K-agency-quality website

Just 7 powerful prompts.

1. The Foundation Prompt
Build me a modern, high-converting landing page for [your business/product].
Include:
- A bold hero headline
- A compelling subheadline
- A clear, high-visibility CTA
- A 3-feature section with icons
- A social-proof/testimonials section
- A clean, professional footer
Design it to feel premium, modern, and trustworthy with strong visual hierarchy, clean spacing, and zero clutter.
Prioritize conversion, readability, and a polished agency-quality look.

2. The Color & Typography System
Create a premium visual system for this website.
Choose:
- 2–3 sophisticated primary colors
- 1 bold accent color for CTAs and key elements
- A modern headline font with strong visual impact
- A clean, highly readable body font
Make the contrast feel luxurious, modern, and intentional — never cheap or overly flashy.
Apply the system consistently across buttons, headings, backgrounds, cards, and other UI elements.

3. The Micro-Interactions Prompt
Add subtle, premium micro-interactions throughout the website.
Implement:
- Smooth hover and press effects on buttons
- Subtle fade-in and slide-up animations as sections enter the viewport
- A sticky navbar that smoothly shrinks slightly when scrolling
- Gentle transitions for interactive elements
Keep animations fast, elegant, and purposeful. Avoid excessive motion or flashy effects.
The goal is to make the website feel polished, modern, and high-end without distracting from the content or slowing down the experience.

4. The Responsive Design Prompt
Make the entire website fully responsive and production-ready across mobile, tablet, and desktop.
- Reflow and stack sections cleanly on smaller screens
- Keep buttons and interactive elements easy to tap
- Maintain consistent spacing, typography, and visual hierarchy
- Prevent horizontal scrolling, clipping, and content overflow
- Optimize images and layouts for different screen sizes
- Ensure navigation and forms remain intuitive on mobile
Test the layout across common viewport sizes and fix any responsiveness issues you find.

5. The Copywriting Prompt
Rewrite all website copy to be persuasive, clear, and benefit-driven — not feature-driven.
Focus on:
- Start with the visitor’s pain point or desired outcome
- Clearly show how [product/service] solves their problem
- Turn features into tangible benefits
- Use simple, confident, conversion-focused language
- Make the value proposition instantly understandable
- Keep every headline under 8 words
- Strengthen CTAs with action-oriented language
Make the copy feel natural, credible, and human — never exaggerated or salesy.

6. The Conversion Prompt
Optimize the website for higher conversions without making it feel aggressive.
- Add a strong secondary CTA immediately after the testimonials section
- Add a simple, low-friction email capture form near the bottom
- Make CTA buttons visually prominent with strong contrast
- Use clear, action-oriented CTA copy
- Keep forms minimal and easy to complete
- Create a clear visual path from problem → solution → proof → action
Make every conversion element feel intentional, trustworthy, and easy to act on.

7. The Final Polish Prompt
Review the entire website as if you were a $10K premium agency designer preparing it for launch.
Audit and improve:
- Spacing and padding consistency
- Typography hierarchy and readability
- Alignment across a clean, professional grid
- Button, card, and section consistency
- Visual balance and whitespace
- Mobile and desktop presentation
- Overall polish and perceived quality
Fix every obvious design inconsistency you find.
Then tell me:
1. What still feels unfinished
2. What is missing from a premium agency-level experience
3. The 3 highest-impact improvements to make next
Do not overdesign it. Keep the final result clean, modern, intentional, and conversion-focused.

💡 How to Use the 7 Prompts
Run these prompts one at a time in the same Claude chat.
Each prompt builds on the previous one, so Claude continuously improves the website instead of starting over.
The result: a polished website that gets better with every step. 🚀
