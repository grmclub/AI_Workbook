##Data analysis prompts

Phase 1: Onboarding & First Look
Use these when handling a new dataset or schema to understand grain, quality, and baseline meaning.
    • First Look / Dataset Profiling:
      "You are a senior data analyst. I just received a new dataset. Look at the columns and sample rows provided. Tell me: 1) What business process or domain does this describe? 2) What is the grain (what does one row represent)? 3) What are the top 3 questions this data can answer, and 3 things it cannot answer?"

    • Data Quality & Schema Validation:
      "Validate this dataset against data engineering best practices. Check for naming conventions (snake_case), mismatched data types (e.g., IDs as float, dates as string), out-of-range numbers, and missing values. Return a clean validation report table with columns: field | issue type | severity (error/warning/info) | description | suggested fix."

Phase 2: Exploratory Data Analysis (EDA)
Use these to uncover hidden patterns, distributions, and statistical relationships.
    • Distribution & Outlier Detection:
      "Analyze all numeric columns in this dataset. Detect statistical outliers, analyze value distributions, and flag any high-cardinality categorical columns (>50 unique values). Recommend the top 3 most interesting patterns or anomalies worth investigating further."

    • Visualization Recommendations:
      "Review this dataset and suggest the 5 best charts or visualizations to uncover key insights. For each chart type, explain the specific variable mapping and the business narrative it will support."


Phase 3: Diagnostic & Advanced Analysis
Use these to break down metric shifts, test hypotheses, or segment data.
    • Root Cause / Metric Drop Diagnosis:
      "Our primary KPI [Insert KPI name] dropped by [X]% over [Timeframe]. Break down this change across our segments [region, channel, customer tier]. Rank the segments by their contribution to the total variance and propose 3 likely root causes to test."

    • Automated Customer Segmentation:
      "Using this dataset, segment the customer records into distinct groups based on behavior, value, or demographics. Provide clear definitions, behavioral characteristics, and strategic recommendations for each segment."
Phase 4: Reporting & Actionable Next Steps
Use these to translate messy outputs into concise executive readouts.
    • Executive Summary:
      "Create a 1-page executive summary based on this analysis. Highlight key findings, major data quality risks, and 3 concrete, prioritized business recommendations with underlying reasoning."

Perfect for quick insight generation.

6. Segment customers automatically

--Design Rules Before You Write Prompts

    Decision owner: who acts on the output.
    Question class: diagnosis, forecast, monitoring, or recommendation.
    Metric contract: exact formulas and exclusions.
    Data boundaries: approved tables, connectors, and freshness limits.
    Validation requirements: null checks, outlier flags, and reconciliation.
    Output contract: table structure, narrative length, confidence statement.

## 36 Prompt Templates by Use Case

A) Business Framing Templates (1-6)

    Decision framing
    Prompt: "Act as a senior analyst. Clarify the decision in one sentence, list the decision owner, define success metric, and request missing context before analysis begins."
    Use when: stakeholder request is broad or ambiguous.

    Scope boundary setup
    Prompt: "Define what is in scope and out of scope for this request. Include geographies, product lines, time window, and data assets allowed for computation."
    Use when: teams debate scope after output is generated.

    Prompt: "Generate three testable hypotheses for the question, rank by business impact, and map required data fields to each hypothesis."
    Use when: early exploratory analysis.

    Decision risk pre-check

    Use when: requests include policy constraints.

    Stakeholder alignment brief
    Prompt: "Draft a one-page analysis brief with objective, constraints, source list, metric definitions, timeline, and review checkpoints."

B) SQL and Data Retrieval Templates (7-12)

    Schema discovery
    Prompt: "Inspect available schema and identify candidate tables for this KPI. Return join keys, grain, and likely duplication risks."
    Use when: new domain onboarding.

    Query draft with assumptions
    Prompt: "Write SQL to compute the metric. Comment all assumptions, filters, and default values inline."
    Use when: fast prototyping with review. Ground joins, grain, and null handling in classical SQL semantics before you trust the draft.

    Use when: many-to-many joins.

    Null and missingness audit
    Prompt: "Quantify null rates per critical field and explain how null handling affects final metric confidence."
    Use when: data quality uncertainty.

    Reconciliation query pair

    Prompt: "Optimize this query for warehouse cost and runtime while preserving metric equivalence. Explain each optimization in plain English."
    Use when: production hardening.

🛠️ 80% of Data Analytics isn’t Math—it’s Maintenance. 
If you’re starting as a Level 1 Data Analyst in 2026, the biggest mistake you can make is chasing complex machine learning models before mastering the 

Data Workflow.
The "fancy" stuff looks great on a resume, but the impact happens in the fundamentals. Here is the 6-step blueprint I use to turn messy rows into business growth:

1️. ASK: Stop and define the "Why." If you don’t know the business problem, you’re just playing with numbers.
2️. PREPARE: Identify your sources. Is it a SQL database, a CSV, or a real-time API stream?
3️. PROCESS: This is the "Data Cleaning" phase. In 2026, we have GenAI copilots to help, but you still need to verify for bias and missing values.
4️. ANALYZE: Use Python or SQL to find the signal in the noise. Focus on descriptive statistics first—know your Mean, Median, and Outliers.
5️. SHARE: Visuals > Spreadsheets. Use Tableau or Power BI to build a story, not just a chart.
6️. ACT: What should the business do tomorrow? If your analysis doesn't lead to an action, it’s just a report.

AI is reducing the value of memorizing SQL syntax, not the value of understanding data.

The analysts who will thrive in the AI era are the ones who combine:
📊 SQL

Here are 10 practical AI prompts every Data Analyst should know.

1. Prompt for Understanding a Dataset
Before analyzing data, you need to understand what you are actually looking at.
Instead of immediately jumping into formulas or SQL, ask AI to help you examine the structure and purpose of the dataset.
Prompt:
"Act as a senior data analyst. I have a dataset containing [describe columns]. Explain what each column could represent, identify the likely business objective of this dataset, and suggest 10 useful questions I could answer using this data."
--Why it helps
This can help beginners develop an analyst’s mindset. Rather than simply calculating numbers, you start thinking about what business questions the data can answer.

2. Prompt for Cleaning Messy Data
Real-world data is rarely perfect.
You may encounter duplicate records, missing values, inconsistent spellings, incorrect formats, unusual characters, or dates stored in different formats.
Prompt:
"Review this dataset as a data-cleaning expert. Identify potential issues such as missing values, duplicates, inconsistent categories, incorrect data types, outliers, and formatting problems. Create a step-by-step data-cleaning plan and explain the reason for each step."
--Why it helps
AI can give you a structured checklist before you start cleaning data manually in Excel, Power Query, Python, or SQL.
The important part is not blindly accepting AI’s recommendations. You should validate every transformation against the original business context.

3. Prompt for Writing SQL Queries
SQL remains one of the most important skills for Data Analysts.
AI can be extremely useful when you know what you want to find but are struggling to construct the query.
Prompt:
"Act as an experienced SQL Data Analyst. I have a table called Sales with columns Customer_ID, Product, Region, Sales_Date, Quantity, Revenue and Profit. Write a SQL query to find the top 10 products by total revenue for each region. Explain the query step by step and mention any assumptions."
--Why it helps
Instead of simply asking AI to "write SQL," giving it the table structure, columns, objective, and expected output usually produces a much more useful result.
It can also help you understand concepts such as:
    JOINs
    GROUP BY
    CTEs
    Subqueries
    Window Functions
    CASE statements
    Ranking
    Date functions

4. Prompt for Finding Trends and Patterns
Finding a number is easy.
Understanding why the number matters is where analytical thinking becomes important.
Prompt:
"Analyze the following sales data and identify the most important trends, patterns, unusual changes, and potential anomalies. Look at revenue, profit, customers, products, and monthly performance. For every major finding, explain why it could matter to the business and suggest one follow-up analysis."
--Why it helps
This encourages AI to move beyond simple calculations and think in terms of business insights.
For example, instead of saying:
"Revenue increased by 18%."
You want to investigate:
"Revenue increased by 18%, but profit increased by only 4%. Could discounts, product mix, or rising costs be responsible?"
That second statement demonstrates much stronger analytical thinking.

5. Prompt for Creating an Excel Formula
Data Analysts frequently spend time creating, debugging, and improving Excel formulas.
AI can act like an on-demand Excel assistant.
Prompt:
"I need an Excel formula that checks whether the customer ID in cell A2 exists in the Customer_Master sheet. If it exists, return the customer’s segment; otherwise return ‘Not Found’. Provide the formula using XLOOKUP and explain how it works."
--Why it helps
Instead of searching through dozens of websites for a formula, you can describe the desired outcome in plain English.
You can also ask AI to:
    Simplify complicated formulas
    Convert formulas into XLOOKUP
    Explain nested formulas
    Troubleshoot errors
    Create dynamic formulas
    Build conditional calculations
However, always test AI-generated formulas with multiple scenarios before using them in important reports.

6. Prompt for Creating DAX Measures in Power BI
Power BI analysts often find DAX challenging because the result depends heavily on context.
AI can help explain and develop DAX measures when the requirements are clearly defined.
Prompt:
"Act as a Power BI and DAX expert. I have a Sales table containing Sales_Date, Product, Region, Revenue and Cost. Create a DAX measure for Profit Margin. Then create a measure to calculate the previous year’s Profit Margin and explain the difference between the two measures."
--Why it helps
This is particularly useful for learning concepts such as:
    CALCULATE
    FILTER
    SUMX
    Time Intelligence
    Context
    Measures
    Variables
The best approach is to use AI not just to generate DAX, but to understand why the DAX works.

The real value comes from explaining what the data means and what the business should do next.

8. Prompt for Checking Your Analysis
Even experienced analysts make mistakes.
A second pair of eyes can be valuable when working with calculations, assumptions, or conclusions.

9. Prompt for Explaining Data to Non-Technical People
One of the most underrated Data Analyst skills is communication.
Your manager may not care about your SQL query or DAX formula. They want to know:

--Why it helps
A strong analyst can communicate with both:

and
Business teams → revenue, customers, costs, risks, opportunities
