[P01] Problem Reframing

text

TEMPLATE ID: P01
USE WHEN: Stuck on a problem / need fresh angle
─────────────────────────────────────────────────
PROBLEM: {{PROBLEM_STATEMENT}}

Reframe this problem in 5 different ways:

1. FROM THE OPPOSITE DIRECTION
   Instead of "how do we X" → 
   "why are we not already X"

2. FROM A DIFFERENT LEVEL
   Zoom out: what bigger problem is this part of?
   Zoom in: what is the smallest version of this?

3. FROM A DIFFERENT STAKEHOLDER
   How does each affected party 
   define this problem differently?

4. AS AN OPPORTUNITY
   What does this problem make possible?

5. WITHOUT YOUR CURRENT CONSTRAINTS
   If constraints didn't exist, 
   how would you define it?

After all 5 reframes:
- Which reframe is most useful? Why?
- What does each reframe reveal 
  that the original missed?

[P08] First Principles Breakdown

text

TEMPLATE ID: P08
USE WHEN: Need to start from absolute basics
─────────────────────────────────────────────────
TOPIC/PROBLEM: {{TOPIC}}

Apply First Principles Thinking.

STEP 1: IDENTIFY ASSUMPTIONS
List everything being assumed as true 
about this problem/topic.
Be exhaustive. Include obvious ones.

STEP 2: CHALLENGE EACH ASSUMPTION
For each assumption:
- Is this actually true?
- What is the evidence?
- What if it were false?

STEP 3: FIND BEDROCK FACTS
What is undeniably, fundamentally true?
Strip away all assumptions.
What remains?

STEP 4: REBUILD FROM SCRATCH
Using only bedrock facts:
- What solutions become available?
- What conventional approaches 
  are actually unnecessary?
- What new approaches emerge?

STEP 5: COMPARE
How does the first-principles solution 
differ from conventional thinking?
What does this reveal?
─────────────────────────────────────────────────
VARIABLES: TOPIC

[A01] MECE Analysis

text

TEMPLATE ID: A01
USE WHEN: Need exhaustive, non-overlapping breakdown
─────────────────────────────────────────────────
TOPIC: {{TOPIC}}

Apply MECE (Mutually Exclusive, 
Collectively Exhaustive) analysis.

STEP 1: IDENTIFY CATEGORIES
Break {{TOPIC}} into categories that are:
- Mutually Exclusive: no overlap between categories
- Collectively Exhaustive: everything is covered

STEP 2: VERIFY MECE COMPLIANCE
□ Do any categories overlap? (fix if yes)
□ Is anything left uncategorized? (fix if yes)
□ Is the breakdown level consistent?

STEP 3: POPULATE EACH CATEGORY
For each category, list all elements.

STEP 4: VALIDATE
Can you think of any element of {{TOPIC}} 
that doesn't fit? 
If yes, adjust categories.

OUTPUT:
- MECE breakdown tree
- Verification checklist
- Gaps identified
- Recommended analysis focus areas
─────────────────────────────────────────────────
VARIABLES: TOPIC

[A05] Pareto Analysis

text

TEMPLATE ID: A05
USE WHEN: Finding 20% causing 80% of impact
─────────────────────────────────────────────────
PROBLEM/DOMAIN: {{DOMAIN}}

Apply Pareto Analysis (80/20 Rule).

STEP 1: LIST ALL FACTORS
List all factors contributing to 
the problem or outcome.

STEP 2: QUANTIFY EACH
For each factor:
- Frequency / Volume / Impact (pick one metric)
- Assign numerical value

STEP 3: RANK AND CALCULATE
| Factor | Value | % of Total | Cumulative % |
|--------|-------|------------|--------------|

STEP 4: IDENTIFY THE VITAL FEW
Which factors account for ~80% of impact?
These are your Vital Few.

Which factors account for the remaining 20%?
These are your Trivial Many.

STEP 5: FOCUS RECOMMENDATIONS
What actions targeting ONLY the Vital Few 
would have the greatest impact?

KEY INSIGHT:
If you could only fix one thing, 
what would it be and why?
─────────────────────────────────────────────────
VARIABLES: DOMAIN
