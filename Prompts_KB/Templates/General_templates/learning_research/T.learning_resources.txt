#Before You Pay for AI Tools Try These 10 Free GitHub Repos First

1. Open WebUI
A self-hosted alternative to ChatGPT
Run leading AI models through a polished interface on your own hardware or server.
• Works with Ollama, OpenAI, Anthropic, Groq, and more
• Team workspaces and user management
• Built-in RAG, web search, and image generation

2. LibreChat
One interface for today's top AI models
Use GPT, Claude, Gemini, DeepSeek, Groq, Mistral, and more in one place.
• Bring your own API keys
• Search previous conversations
• Save reusable prompts and presets

3. ComfyUI
Advanced AI image and video creation
A powerful node-based workflow builder for creative AI projects.
• Supports FLUX, SD3, WAN, Hunyuan, and more
• Image-to-video, inpainting, and ControlNet
• Thousands of community-built custom nodes

4. Ollama
Run powerful AI models locally
Download and run open-source models directly on your computer.
• Supports Llama, Qwen, Gemma, Phi, Mistral, and more
• Keeps your data on your device
• OpenAI-compatible local API

5. Langflow
Build AI agents without starting from scratch
Create AI workflows with a visual drag-and-drop builder.
• Visual workflow editor
• Export as Python or API
• Connects to popular vector databases

6. n8n
Automate workflows with AI
Connect apps, AI models, and APIs using visual workflows.
• 400+ app integrations
• Native AI and LLM nodes
• Supports agents, webhooks, and scheduled automations

7. AnythingLLM
Private AI chat for your own knowledge
Ask questions across your documents while keeping your data under your control.
• Works with PDFs, websites, Notion, and Confluence
• Compatible with many LLMs and vector databases
• Built-in AI agent support

8. Perplexica
Open-source AI search with citations
Search the web using your preferred AI model.
• Supports SearXNG and multiple LLMs
• Research modes for YouTube, Reddit, writing, and more
• Self-hosted with no tracking

9. CrewAI
Build teams of AI agents
Create specialized AI agents that work together to complete complex tasks.
• Role-based AI agents with memory and tools
• Sequential or hierarchical workflows
• Works with many LLM providers

10. Dify
An open-source platform for AI apps
Build, test, and deploy AI applications from one platform.
• Prompt management, RAG, and AI agents
• Visual workflow builder and API gateway
• Self-hosted or cloud deployment
