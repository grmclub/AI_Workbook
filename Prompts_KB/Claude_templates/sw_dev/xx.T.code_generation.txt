##Claude super prompts
https://superprompt.com/library

"Super prompts" in the Claude ecosystem combine two primary concepts: Anthropic's "Skills" feature (for creating reusable AI capabilities) and highly optimized, expert-level prompt frameworks designed to get deep, precise, and literal reasoning out of the model. 

1. The Super Prompt Framework (The 6-Part Anatomy)
To generate elite-level outputs across writing, coding, or strategy, use this modular super prompt structure: 

Role: Define exactly who Claude is (e.g., “You are a Principal Software Architect with 15 years of experience in distributed systems...”).
Context: Provide background on your constraints, audience, or brand.
Objective: State clearly what needs to be done.
Reasoning: Instruct the model to draft its logic step-by-step before executing the work.
Output Schema: Define the exact formatting (e.g., “Respond with an array of markdown tables” or “1. Context, 2. Root Cause, 3. Fix”).
Hard Limits: Avoid vague words like "be concise". Use explicit limits: “Maximum 3 sentences” or “Limit to exactly 5 bullet points”. 

2. High-Utility "Super Prompt" Templates
For Pressure-Testing a Business Idea
Copy and paste this when evaluating a new venture: 
Act as a veteran venture capitalist who reviews thousands of pitches. Pressure-test my business idea. Do not be polite. My idea is: [Insert Idea]. First, detail the 5 most likely ways this business will fail. Next, analyze 3 existing alternatives that customers currently use, and explain exactly how to pull customers away from them. Finally, give me a brutally honest assessment: Would you invest your own money, and what must change for that answer to be yes?
For Code & System Architecture
Use this framework to force robust, accessible, and documented code: 

Act as a Senior Full-Stack Engineer. I need you to implement a [Feature Name]. Before writing any code, outline your architectural philosophy, edge-case handling strategy, and any accessibility considerations. Ensure the solution is modular. Output the response in three sections: 1) Architecture & Flow (bullet points), 2) Implementation Details (code blocks), and 3) Testing & Validation steps.
For Copywriting & Content Creation
Use this for safe yet creative variations: 

I need a piece of marketing copy for a [Product/Service]. First, analyze the target audience. Next, generate two distinct drafts: Draft 1 should be conventional, safe, and highly structured. Draft 2 should take a real creative risk. Afterward, provide a brief critique comparing the two in a markdown table.

3. "Skills" (Claude's Built-In Super Prompts)
If you are tired of typing massive, repetitive prompts, you can use Claude’s built-in Skills feature. 
What it is: Instead of re-explaining your work methodology every time, you can instruct Claude to build reusable, composable capabilities (e.g., a "Job Search Strategist" or "Financial Analyzer").
How to use: Store your context, step-by-step instructions, and formatting preferences in a markdown file. Claude can then access these files in any conversation, allowing you to invoke complex multi-step workflows with a single click.

01. Plan Mode (Shift + Tab)
Before any implementation, switch to plan mode. Claude Code analyzes your codebase and creates an architecture plan WITHOUT writing any code. Review the plan. Approve it. Then switch back to implementation. This single habit prevents more bugs than any other technique on this list.

02. Compact (/compact)
After 30 to 45 minutes of conversation, your context gets bloated. Type /compact to compress the entire conversation history into a focused summary of key decisions and current state. Claude Code stays sharp instead of gradually losing track of what you discussed.

03. Clear (/clear)
Starting a new task? Clear the slate entirely. Carrying context from a database refactor into a frontend redesign produces confused, conflicting code. One conversation per feature. Always.

04. Init (/init)
Run this at the start of any new project. Claude Code scans your codebase and generates a CLAUDE▪︎md file. a persistent context document that it reads automatically in every future session. Includes project structure, tech stack, coding patterns, and key architecture decisions

05. The Cost Check (/cost)
Displays your token usage for the current session. Check this every hour during long sessions. AI-assisted development costs money and surprises are never fun. Set a mental budget per session and check against it.

06. Memory (/memory)
Add persistent instructions that Claude Code remembers across all sessions. "Always use TypeScript strict mode." "Always add JSDoc comments to public functions." "Always run tests after modifying any file in /src/core." These rules apply automatically in every future conversation without repeating them.

07. Terminal Integration (! prefix)
Prefix any message with ! to run it as a terminal command instead of sending it to Claude. Quick way to run tests, check git status, or navigate directories without leaving the Claude Code interface.
