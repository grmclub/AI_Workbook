1/ Claude + ChatGPT Frameworks: L-A-U-N-C-H + S-C-A-L-E
Use L-A-U-N-C-H when you need to introduce an offer, campaign, piece of content, or new idea with clarity.
➔ Leverage: Start with the assets you already have.
➔ Audience: Define exactly who you want to reach.
➔ Use Case: Clarify the problem you are solving.
➔ Narrative: Shape the story or positioning.
➔ Channels: Decide where the message should appear.
➔ Hook: Create the angle that earns attention.
Example: LinkedIn lead generation for SaaS founders.
Use S-C-A-L-E when you need to turn working activities into a repeatable growth system.
➔ System: Define the process.
➔ Constraints: Know your time, budget, and limits.
➔ Automation: Identify what can run automatically.
➔ Levers: Use content, ads, partnerships, or other growth drivers.
➔ Expansion: Decide how the system can grow.
Example: A solo founder building a multi-platform content engine.

2/ Claude + ChatGPT Frameworks: O-U-T-P-U-T + C-A-P-T-U-R-E
Use O-U-T-P-U-T when you want Claude to produce a more precise result instead of a vague answer.
➔ Objective: Define the desired result.
➔ User: Clarify who the output is for.
➔ Task: State exactly what needs to be done.
➔ Process: Explain how the task should be approached.
➔ Upgrade: Improve or optimize the first result.
➔ Test: Check whether the output actually works.
Example: An agency creating a high-converting lead magnet.
Use C-A-P-T-U-R-E when the goal is content that moves people from attention to action.
➔ Context: Set the situation.
➔ Attention: Earn the first few seconds.
➔ Pain: Surface the relevant problem.
➔ Trigger: Give the reader a reason to care now.
➔ Utility: Provide something useful.
➔ Result: Show the desired outcome.
➔ Engagement: Give the audience a next action.
Example: Low engagement → bold hook → growth pain → useful solution → comment CTA.

3/ Claude + ChatGPT Frameworks: G-R-O-W-T-H + C-O-N-V-E-R-T
Use G-R-O-W-T-H when you need execution clarity inside ChatGPT.
➔ Goal: Define the outcome.
➔ Resources: List what is available.
➔ Obstacles: Identify what could block progress.
➔ Workflow: Map the steps from start to finish.
➔ Tools: Choose what supports the workflow.
➔ How to Measure: Decide how success will be tracked.
Example: Use ChatGPT + Canva to create scalable content, then measure leads generated.
Use C-O-N-V-E-R-T when you are shaping an offer or sales message.
➔ Customer: Who is buying?
➔ Offer: What are you selling?
➔ Need: What problem makes it relevant?
➔ Value: Why is the outcome worth paying for?
➔ Evidence: What supports the claim?
➔ Risk Reversal: Reduce the buyer's perceived risk.
➔ Trigger: Define the next action.
Example: AI automation offer → free trial → book-a-call CTA.

4/ Claude + ChatGPT Frameworks: B-U-I-L-D + P-O-S-I-T-I-O-N
Use B-U-I-L-D when you want ChatGPT to help turn an idea into a product, content asset, or business resource.
➔ Base Idea: Start with the core concept.
➔ Users: Define who needs it.
➔ Implementation: Decide how it will be created.
➔ Leverage: Identify what helps it scale.
➔ Distribution: Plan how people will discover it.
Example: AI tool directory → SEO + LinkedIn.
Use P-O-S-I-T-I-O-N when you need clearer brand or market positioning.
➔ Problem: What pain exists?
➔ Opportunity: What gap is available?
➔ Solution: What do you provide?
➔ Identity: What should the brand stand for?
➔ Trust: Why should people believe you?
➔ Influence: Where do you build attention?
➔ Offer: What can people buy?
➔ Next Step: What should they do next?
Example: AI educator → content + community → course.
The bigger lesson is simple: random prompting gives AI too much room to guess. Clear frameworks force you to define the goal, audience, process, value, and next step before asking the tool to help.
