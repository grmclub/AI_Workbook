## Custom Slash-Command Modular Toolkits
You can prepend these short tags to your queries to instantly lock the AI into a specific lens, workflow, or formatting boundary.

💡 Thinking Styles

    /analyst         — Deep analysis
    /critic          — Find flaws only
    /optimizer       — Improve what's given
    /simplify        — Explain like a beginner
    /eli5            — Very simple explanation
    /deepdive        — Go very detailed
    /compare         — Compare options
    /proscons        — List pros and cons
    /firstprinciples — Break down to basics
    /contrarian      — Challenge the idea
    /devil           — Argue the other side
    /steelman        — Best version of an argument

🎯 Productivity System

    /plan            — Daily plan
    /weekly          — Weekly plan
    /prioritize      — What to do first
    /focus           — Remove distractions
    /automate        — Automation ideas
    /delegate        — What to delegate
    /habits          — Habit building
    /track           — Tracking system
    /timeblock       — Time blocking
    /review          — Weekly review
    /morningroutine  — Start your day right
    /batchtasks      — Group similar tasks

⚡ Execution & Output Formats

    /ghost           — Final answer only, no explanation
    /minimal         — Shortest possible response
    /brief           — 3 to 5 lines max
    /expand          — Detailed explanation
    /stepbystep      — Clear steps
    /checklist       — Actionable checklist
    /framework       — Structured framework
    /blueprint       — Implementation plan
    /playbook        — Repeatable system
    /roadmap         — Timeline-based steps
    /draft           — Rough first version
    /polish          — Clean and refine output

💼 Business / Strategy Slash-Commands

    /startup         — Startup idea
    /gtm             — Go-to-market plan
    /monetize        — Revenue ideas
    /validate        — Validate idea
    /icp             — Ideal customer profile
    /sales           — Sales pitch
    /coldoutreach    — Cold outreach
    /offer           — Offer creation
    /funnel          — Funnel strategy
    /retention       — Retention ideas
    /positioning     — Brand positioning
    /competitor      — Competitor analysis

##30 Claude Shortcut Hacks

🧠 Quick Comprehension
    /eli5         — Explain simply
    /tldr         — Summarize fast
    /briefly      — Keep it short
    /exec summary — Give key takeaways

🏗️ Structure
    /step-by-step — Break into steps
    /checklist    — Make it actionable
    /schema       — Create structure
    /pm mode      — Focus on delivery

👤 Persona
    /act as       — Assign persona
    /audience     — Adapt to reader
    /tone         — Set the voice
    /jargon       — Use expert language
    /dev mode     — Be technical/direct

📤 Output Control
    /begin with        — Control opening
    /role:task:format  — Define assignment
    /end with          — Control closing
    /guardrail         — Set strict boundaries
    /why               — Explain reasoning
    /first principles  — Start from basics

🔍 Analysis
    /pitfalls            — Find risks
    /metrics mode        — Use KPIs/data
    /debate              — Challenge ideas
    /deliberate thinking — Slow down reasoning
    /rewrite as          — Change style

🛡️ Critical Thinking & Analysis
    /reflective mode     — Review the answer
    /no autopilot        — Avoid generic output

🗺️ Strategic
    /multi-perspective   — Show viewpoints
    /compare             — Show trade-offs
    /swot                — Analyze strengths/risks
    /parallel lenses     — Analyze by angles
